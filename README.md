# AI1117

موقع دليل مقرر **الذكاء الاصطناعي وتطبيقاته (0/1117)** – جامعة القدس المفتوحة، فرع الخليل.
إعداد: أ. أحمد عوني النتشة.

## نبذة
موقع بسيط يجمع تعليمات المقرر والموارد الأساسية في مكان واحد لطلبة شعب الأستاذ أحمد عوني النتشة، ويوضّح:

- **الجانب النظري (50 علامة):** الوحدات التأسيسية 1–4 إلزامية للجميع، ومنها فقط الامتحان النهائي النظري.
- **الجانب العملي (50 علامة):** يختار الطالب مسارًا واحدًا، ولكل مسار 3 وحدات تطبيقية يُبنى عليها المشروع والامتحان العملي.

## الصفحات
- الصفحة الرئيسية
- تعليمات المقرر
- اختيار المسار
- مشروع المسار
- نموذج تقرير المشروع (غلاف التقرير)
- الأسئلة الشائعة
- الموارد والأدوات

## هيكلة المشروع
```
index.html                  الصفحة الرئيسية
css/style.css               ملف التنسيق
js/main.js                  وظائف تفاعلية بسيطة
pages/                      بقية صفحات الموقع
files/report-sample.docx    غلاف تقرير المشروع
images/                     صور الموقع
```

الموقع ثابت (HTML/CSS/JS) بدون قواعد بيانات، ويُنشر مباشرة على GitHub Pages.

## حقوق الاستخدام
هذا الموقع مخصص فقط لطلبة مقرر الذكاء الاصطناعي وتطبيقاته في جامعة القدس المفتوحة – فرع الخليل،
ولا يجوز إعادة نشره أو استخدامه في مقررات أخرى دون إذن صاحب العمل.
